## Editorial principles

**One official current guide per topic.** Each guide should begin by explaining who it helps, where the reader starts, and what specific action they should take. Supporting checklists and templates exist only when they serve a different purpose from the main guide.

**Practicality over generic advice.** Explain the process, give a concrete example, say where readers can find reliable information and distinguish a confirmed outcome from a hypothesis. Never fabricate metrics, experiences, references, buyers, grants or eligibility.

**Official requirements versus helpful recommendations.** Government rules, employers' published criteria, visa document limits and safety obligations are distinguished from suggested study plans, AI prompts and business-development activities.

**Responsible publication.** Make factual claims from appropriate current primary sources. Keep sensitive details private, identify permissions to use data and never imply that a checklist guarantees a job or endorsement.

## Navigation and Markdown testing

| Check | Latest observed result | Important limit |
| --- | --- | --- |
| Known library files | **47 active Markdown files** organised by category | Other unlisted assets are outside this inspection |
| Internal navigation | Links and headings inspected during editing; a further broad check is documented below | Automated path matching does not replace a real browser |

| Global Talent plans | **24 months each** across three pathways | Timelines are optional development suggestions |
| Passport renewal | Clear route-selection steps without copied page markers or conflicting fee summaries | Requirements can change at the application portal |
| Interactive Excel companions | Markdown tracker guidance is available, but interactive Excel files are not provided here | Do not claim workbook formulas are available online |
| Public GitHub access | Repository remains **private** until authorised visibility is changed | Community access requires a publishing decision |

## Final release gates still to complete

| Priority | Required action | Why it matters |
| --- | --- | --- |
| **High** | Independently verify all material immigration claims against GOV.UK, NIS and current specialist assessor guidance | Legal or application errors can be costly |
| **High** | Visit key third-party programme/opportunity URLs and record live intake, eligibility and country restrictions | A useful link may lead to a closed or restricted programme |
| **High** | Check active Innovator Founder endorsing bodies and current charges at application time | Government authorisation and provider terms can change |
| **Medium** | Test all code/CLI exercises in a safe repository | A command example may be version-sensitive or destructive |
| **Medium** | Review policy documents with a designated Mettelo approver | Guidance should not imply that unconfigured controls are enforced |
| **Medium** | Test selected long guides and tables on desktop and mobile | Readability matters to members using phones |
| **Medium** | Have a beginner test CV, NHS application and business-discovery paths | Reveals gaps invisible to authors |
| **Medium** | Decide how to make private resources accessible to the intended community | Private links do not work for non-members |

## Recent improvements

**Innovator Founder:** The guide has been rebuilt around a detailed UK market discovery workflow with **12 specific opportunity hypotheses**, ONS and procurement research, real customer interviews, competitor differentiation, pilot evidence, practical financial/scale modelling, a **90-day plan**, **12-month roadmap**, relevant organisations and official endorsement requirements.

**Official hub presentation:** The guides now use reader-focused Mettelo wording. Technical notes about file conversions, document page counts and retired editions have been removed from the public-facing descriptions. Information about real **data sources** and independently verified public references is retained because those are necessary to support factual claims.

**Other categories:** Career, government application, technical and immigration resources remain linked from [Start Here](START_HERE.md) and the [complete directory](RESOURCE_INDEX.md).

## How members can report an issue

[Open a GitHub issue](https://github.com/Mettelo/mettelo-resource-hub/issues) with the exact guide URL, section, what is unclear or inaccurate and an official reference where possible. **Never post personal immigration, patient, customer or employer-confidential material in public issues.**
