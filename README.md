## Getting started

1. Choose a category above.
2. Open a guide using its link.
3. Follow the instructions and copy any prompts or templates you need.
4. Check the guide's status and review date before relying on time-sensitive information.

The repository structure is ready. The original guides have **not yet been converted or published** as Markdown. The [resource index](RESOURCE_INDEX.md) tracks what is planned, in review and available.
