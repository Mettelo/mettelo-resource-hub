## What is actually inside the Excel trackers?

Each of the three supplied workbooks contains two worksheets:

| Worksheet | How it works |
| --- | --- |
| **Checklist** | Shows tasks and a Status field. The other columns are **Target date**, **Saved file link** and **Notes or what is missing**. |
| **Progress log** | Records **Date**, **What I did and the actual result**, **Evidence file link**, **My next step** and **Target date**. |

The Technology and Arts worksheets show an **Items marked Ready** count, accompanied by the original warning that **Ready is not an eligibility decision**. Their checklists each contain **18 tasks**.

The Research checklist is different: **cell B4 chooses a research route**, and formula-driven rows change according to that choice. The actual workbook options are **Appointment**, **Approved fellowship**, **UKRI funded role**, **Peer review promise** and **Peer review talent**. The first six tasks change with this choice; six follow-up tasks remain. Do not mix requirements from distinct routes.

### How to use the Checklist worksheet

1. Select the correct route before collecting documents, particularly for the research tracker.
2. Read the matching detailed guide and independently check its current official requirements.
3. Review each item. Change the status from **To do** as you work, and record a target date.
4. Store your documents somewhere **private and access-controlled**. Paste a private evidence link into the **Saved file link** column; never expose it in a public pull request or GitHub Issue.
5. Use **Notes or what is missing** to identify a remaining action, uncertainty or required confirmation.
6. Mark **Ready** only after reviewing the real evidence. Use **Not needed** only when the requirement genuinely does not apply.
7. Record important completed work separately in **Progress log** with dates, outcomes, supporting evidence, and next steps.

## Which format should you use?

**Markdown** works best for reading checklists, understanding the process and finding the detailed guides on GitHub. Members can copy a checklist to their private notes and tick items off.

**Excel** works best for personal evidence tracking, saved document locations, progress dates and — particularly for the research workbook — its formula-driven route selection. Do not convert spreadsheet formulas into a static Markdown table and claim they still work.

## Source-specific cautions

- Technology: the source includes category selection, CV, three recommendations, recognition and criterion evidence, document limits, translations and application tasks.
- Arts: the source is for the **general arts pathway**, not every specialist creative discipline. It distinguishes media, prizes and professional appearance evidence.
- Research: the route selector matters. For example, the source has specific UKRI funding amounts and time periods; these are **source claims**, not newly confirmed 2026 rules.
- All trackers: evidence files, referee information and application records may contain personal or confidential material. Do not commit them to Mettelo's public GitHub repository.

## Before relying on the checklist

The original materials were prepared in October 2026. Requirements can change. Use the relevant official GOV.UK route as the final authority, especially for eligibility, document caps, evidence standards, fees and application steps:

- [GOV.UK — Global Talent visa overview](https://www.gov.uk/global-talent)
- [Digital technology](https://www.gov.uk/global-talent-digital-technology)
- [Arts and culture](https://www.gov.uk/global-talent-arts-culture)
- [Research and academia](https://www.gov.uk/global-talent-researcher-academic)
