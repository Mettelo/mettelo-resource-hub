# Professional Project Experience & Capability Catalogue

**How to use the Mettelo evidence workbook**

> **Status:** Markdown instructions created from the original `Professional Project Experience Catalogue.xlsx`. The original **interactive Excel workbook has not been uploaded to GitHub**. This guide does not claim that the Capability Report formulas, dropdowns or cross-sheet summaries run in Markdown.

## Purpose

Use the workbook to record genuine project and work examples, then review the capabilities demonstrated. The file is useful for maintaining an evidence bank before writing CVs, employment histories, personal statements or preparing for interviews.

## Workbook structure

The uploaded workbook has **seven worksheets**:

| Worksheet | Purpose |
| --- | --- |
| **Start Here** | Instructions and register of experience worksheet names |
| **Mettelo Ltd** | Example experience sheet |
| **Company B** | Additional example experience sheet |
| **Company C** | Additional example experience sheet |
| **Company D** | Additional example experience sheet |
| **Dropdown Options** | Behaviour/competency, technical skills, impact and STAR status selections |
| **Capability Report** | Summarises recorded experiences, STAR completion, impact, behaviours, technical skills and development priorities |

> The company worksheets contain the **same generic demonstration example** in row 2. The example “Improved the Reliability of a Recurring Data Report” is illustrative and **must not be presented as verified personal experience**. Real entries start in row 3.

## Start with the Excel workbook

1. **Create a sheet:** Copy an existing experience sheet for each employer, client, course, volunteering role, portfolio or personal project.
2. **Rename the tab:** Use a short, meaningful name, such as `Client Project` or `Personal Portfolio`.
3. **Register the sheet:** On **Start Here**, type the exact worksheet tab name into the register. Spelling and spaces must match.
4. **Add real evidence:** Start at row 3 of the experience worksheet. Record one distinct experience per row.
5. **Review the summary:** Visit **Capability Report** to understand recorded evidence, STAR completion, capability strengths and possible gaps.

**Important:** Changing a worksheet name without updating the **Start Here** register can break the intended reporting workflow. Check the workbook after adding new tabs.

## Fields in each experience sheet

The source includes these eleven columns:

| Field | What to record |
| --- | --- |
| Date | Date of the work or project milestone |
| Experience or Project | Short, descriptive title |
| Situation or Context | Problem, background, risk or service need |
| Responsibility or Objective | Your actual responsibility |
| Actions Taken | What you personally did, including relevant decisions |
| Outcome or Result | Confirmed result, limitation or improvement |
| Behaviour or Competency | Relevant behaviour evidenced by this example |
| Technical Skill or Method | Real tool, skill, professional method or framework used |
| Impact Rating (1 to 5) | Your evidence-based self-assessment, not an employer score |
| STAR Complete? (Yes / Developing / No) | Whether your record has enough evidence |
| Supporting Notes | Clarification, evidence source or further questions |

Do not invent a result or inflate a personal contribution to increase an impact rating. Distinguish personal work from team work and estimates from confirmed measurements.

| YYYY-MM-DD | [Your actual project] | [Real problem] | [Your role] | [Real steps taken] | [Verified outcome] | [Relevant behaviour] | [Tool used] | [1–5] | Developing | [What needs checking?] |

For lengthy accounts, use the Excel workbook rather than trying to fit every action in a narrow Markdown table.

## Understand the Capability Report

The **Capability Report** is a spreadsheet summary of the experience sheets registered in **Start Here**. It is designed to help review the number of experiences, STAR completion, recorded impact, behavioural competencies, technical skills and development priorities.

Use it to identify where you already have sound evidence and where you need to clarify your contribution. **It is not an official recruitment scoring system**, nor a guarantee that a given CV or answer will pass a shortlist.

## What can and cannot migrate to Markdown?

**Works in Markdown:** Explanations, instructions, field definitions, blank templates and static sample tables.

**Requires Excel or a purpose-built application:** Workbook formulas, dropdown selections, automatic updates when adding rows and sheets, the dynamic Capability Report and any interactive filtering or calculation.

For the Mettelo Resource Hub, the recommended publication model is **this Markdown guide plus the original workbook as an optional downloadable companion**. That downloadable workbook remains outstanding.

## Information safety

Never store passwords, confidential company names, restricted links, personal identifying data or customer records in public evidence. Share only approved, anonymised examples. Keep your completed workbook private unless you have reviewed every field for publication and obtained all necessary permissions.
